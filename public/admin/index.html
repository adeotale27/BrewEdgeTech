Safety & access

Admin APIs are protected by secure, server-side session authentication (HTTP-only signed cookies). The public site can display published content only. Do not put passwords or API keys in editable content.

Credentials are configured via environment variables (ADMIN_USERNAME, ADMIN_PASSWORD, ADMIN_SESSION_SECRET). Sessions expire automatically after 8 hours.
